# V-Studio: стан переробки

Оновлено 2026-09-18. Попередній аудит і перелік ідей збережені в [архіві](docs/roadmap-2026-06.md). Старе твердження про «відмінний технічний стан» не означало завершеного користувацького сценарію.

## Що змінилося

- **Аврелія** — нова повноцінна 3D-модель із геометрією, скелетом, мімікою та оглядом на 360°. Доступні обертання камери, масштабування, фронтальний вигляд, автоматичний огляд, перегляд сітки та GLB-експорт.
- Основа Аврелії — ліцензований VRM-зразок pixiv; анатомія, базова геометрія, текстури та риг створені pixiv. V-Studio додає власне оформлення матеріалів та об’ємні аксесуари. [Джерело й умови](public/models/aurelia-3d/README.md) збережено разом із моделлю.
- Нова студія відкриває Аврелію в портретному кадрі. Раніше збережені персонажі й JSON-проєкти зберігають свій рендерер, включно з Мією. Моделі без `modelId` трактуються як параметричні.
- **Мія Ноктюрн** залишається окремою ілюстрованою 2D-моделлю: сріблясто-лавандове волосся, бірюзові очі та небесне вбрання. Її рендерер використовує мальовані шари, деформацію сітки та рухомі деталі обличчя.
- Для Мії доступні портретне кадрування, вид до пояса, повна наявна ілюстрація та місячне сяйво. Ці параметри зберігаються в проєкті й застосовуються до експорту та OBS. У вкладках зовнішності показуються робочі параметри цілісної ілюстрації.
- PNG-портрет, автономний SVG із вбудованими зображеннями та Telegram PNG підтримують ілюстровану модель. TGS для неї вимкнено; векторний експеримент залишається лише для параметричних персонажів.
- Аврелія підтримує PNG із реальної 3D-сцени, Telegram PNG та GLB. SVG і TGS для 3D-моделі вимкнені. Три рівні жвавості рухів, кадрування й метадані зберігаються разом із персонажем.
- Робоча область навколо персонажа: візуальна бібліотека, зрозуміла навігація, емоції, фон перегляду, масштаб, портрет і стікерпак поруч із полотном.
- Перемальовані зачіски, очі, обличчя та плечі, деталі одягу й узгоджений стартовий образ. Виправлено конфлікти градієнтів у галереї та відсутні заливки при зміні емоцій.
- Історія на 60 кроків, групування редагувань, скасування імпорту й операцій із колекцією. Імпорт перевіряється перед застосуванням; пошкоджені локальні записи відновлюються без падіння редактора.
- Основний Telegram-сценарій: прев’ю → вибір реакцій → справжні PNG 512 × 512 → ZIP із файлами, емодзі та інструкцією для @Stickers. Експериментальний TGS позначено окремо.
- Портрет PNG 1600 × 1600, прозорий фон, робоча пауза/відновлення анімації, мобільна навігація без горизонтального переповнення.
- Парний URL для OBS замість спільного потоку всіх користувачів сервера.
- ШІ-стиліст пояснює свої можливості, пропонує приклади та показує відсутність підключення до відправлення запиту.

## Що перевіряється автоматично

Перевірки запускаються командами з README: TypeScript, ESLint, Prettier, unit-тести, Playwright і production build. Попередні результати MVP не замінюють перевірку нової моделі.

Автоматичні сценарії охоплюють обертання 3D-моделі, вміст GLB, відповідність рухів скелету й міміці, формати зображень, прозорість, поля стікера, відмінності реакцій, ZIP-маніфест, автономність SVG, анімацію ілюстрованих шарів, сумісність старих проєктів, undo/redo, імпорт/експорт, пошкоджені дані, мобільне компонування, доступність та ізоляцію OBS-сесій. Перевірки TGS стосуються параметричних персонажів.

## Реальні межі

- Публікація набору відбувається через @Stickers користувачем. ZIP сам по собі не є опублікованим Telegram-паком.
- GLB Аврелії зберігає геометрію, скелет, ваги шкіри, текстури та морфи обличчя. Експорт використовує PBR-матеріали з іншим виглядом, ніж MToon у студії. Це не VRM-експорт: прив’язки емоцій VRM, пружні кістки та анімаційний контролер студії не переносяться.
- TGS не підтримує растрові шари Мії. Для старих векторних персонажів конвертація TGS поки не гарантує відповідності оригінальному SVG; для точної графіки призначений PNG.
- Мія — ілюстрована 2D-модель з обмеженою деформацією пози, а не повноцінна 3D-модель чи Live2D Cubism. Немає експорту `.moc3`, відновлення прихованих поверхонь або довільної зміни костюма. Повний кадр показує наявний малюнок, а не домальовує тіло поза ним.
- SVG-експорт Мії містить вбудовані растрові зображення й відкривається самостійно; це не переведення ілюстрації у вектор.
- Параметричні персонажі лишаються редагованими векторними конструкторами. ШІ-стиліст підбирає їхні деталі; він не генерує новий малюнок і не перемальовує Мію.
- Збереження локальне, без облікових записів і хмарної синхронізації. Файл проєкту — резервна копія.
- Приймання Telegram, реальну камеру/мікрофон і OBS слід перевіряти на цільових пристроях, окремо від браузерних автотестів.

## Наступні продуктові кроки

1. Ручна перевірка PNG-набору в Telegram Desktop / Android / iOS та роботи трекінгу у цільових браузерах.
2. Полірування 3D-моделі, одягу, зачісок та рухів на крайніх позах; візуальні еталони для регресій і перевірка продуктивності на цільових пристроях.
3. Для анімованих стікерів 3D- та ілюстрованих моделей — окремий перевірений Telegram-сумісний відеоекспорт. Для параметричних TGS — перевірка анімацій відповідним рендерером.
4. За потреби — підключення Telegram-бота для публікації, авторизація й хмарна бібліотека як окремий завершений сценарій.

Нове налаштування має узгоджено пройти `types → renderer → editor → sanitizeConfig → uk/en → export`; схема ШІ додатково оновлюється для параметричного конструктора. Художня цілісність і рух моделі важливіші за кількість параметрів.
