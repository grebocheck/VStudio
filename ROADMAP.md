# V-Studio — Роадмеп кастомізації аватарів

> Проєкт **VTuber Customizer & Live Rigging Studio** вже має міцну продуктову основу: детальний SVG-аватар із 3 арт-стилями, 16 емоціями, MediaPipe-трекінг, персистентність, експорт, OBS overlay, Telegram sticker pack, кліпи, unit/E2E-тести й CI.
>
> Цей роадмеп фокусується на **поглибленні кастомізації аватарів** — нових візуальних елементах, розширенні кольорових систем, анатомічних деталях і механіках виразності.
>
> Дата: 2026-06-04 · Гілка: `main`

## Фаза A — Нові візуальні елементи (розширення бібліотеки)

Мета: суттєво збільшити кількість комбінацій, щоб кожен аватар був унікальним.

### A1. Нові зачіски

- [ ] **Bangs:** `asymmetric` (різна довжина зліва/справа), `blunt-bangs` (рівно відрізана пряма чілка), `messy` (хаотично-творчий стиль), `braided-bangs` (коси-чілка як у скандинавських воїнів)
- [ ] **Back styles:** `side-tail` (хвіст збоку), `twintail-long` (довгі два хвости з стрічками), `messy-bun` (розлохмачений пучок), `fishtail-braid` (коса «риб'ячий хвіст»), `layered` (багатошарова каскадна стрижка)
- [ ] Фізика волосся для нових стилів: sway/bounce у `hairPhysics.ts`

### A2. Нові костюми

- [ ] `school-blazer` — класичний шкільний блейзер із краваткою
- [ ] `chinese-dress` (qipao) — традиційне китайське плаття з мереживом
- [ ] `pirate-coat` — піратський камзол із золотими ґудзиками та плечовими погонами
- [ ] `angel-dress` — ефірне біле плаття з крилами та золотим поясом
- [ ] `punk-jacket` — шкіряна куртка з шипами, нашивками та рваними елементами

### A3. Нові аксесуари

- [ ] `eye-patch` — піратська пов'язка на оці (SVG-маска над одним оком)
- [ ] `flower-crown` — вінок із квітів (троянди, лаванда, ромашки)
- [ ] `hair-ribbons` — стрічки у волоссі (різні кольори)
- [ ] `choker` — чокер на шиї (шкіра, мереживо, ланцюжок)
- [ ] `earrings` — сережки (кільця, зірки, краплі)
- [ ] `tiara` — витончена тіара замість масивної корони
- [ ] `demon-wings` — декоративні крильця (маленькі демонічні, за плечима)
- [ ] `scarf` — шарф / хустка на шиї

### A4. Нові зіниці (pupil styles)

- [ ] `spiral` — гіпнотична спіраль
- [ ] `crescent` — півмісяць
- [ ] `infinity` — символ нескінченності ∞
- [ ] `cat-vertical` — вертикальна щілина як у кішки (відрізняється від `slit` товщиною і закругленням)

## Фаза B — Розширена кольорова система та стилізація

Мета: більше контролю над кольорами та візуальними ефектами.

### B1. Мульти-тоновe волосся

- [ ] `hairColor2` — другий колір для реального двотонового фарбування (ombré, split-dye)
- [ ] Нові градієнти: `split` (ліва/права половина різного кольору), `rainbow`, `tips-only` (тільки кінці)
- [ ] Візуалізація через SVG `<linearGradient>` та `<radialGradient>` із позиціонуванням

### B2. Кольори шкіри та губ

- [ ] Palette picker із преднастроєними тонами шкіри (fair, light, medium, tan, dark, fantasy-blue, fantasy-green)
- [ ] `lipColor` — окремий колір губ / контуру рота
- [ ] `lipStyle` — `natural`, `glossy`, `dark`, `gradient` (ombre-губи)

### B3. Просунуті кольорові схеми одягу

- [ ] `clothingColor3` — третій колір для акцентів (ґудзики, декор, підкладка)
- [ ] `clothingPattern` — патерни поверхні: `stripes`, `plaid`, `polka-dots`, `camo`, `gradient` (реалізовано через SVG `<pattern>`)
- [ ] Texture overlay прозорість (регульована інтенсивність патерну)

### B4. Аксесуарна палітра

- [ ] `accessoryColor2` — другий колір для двоколірних аксесуарів (стрічки у bunny-ears, дужки glasses тощо)
- [ ] Material presets: `metallic`, `matte`, `glossy`, `holographic` — різні SVG-фільтри для поверхні аксесуарів

## Фаза C — Анатомія та деталізація обличчя

Мета: зробити обличчя більш виразним і деталізованим.

### C1. Розширені деталі очей

- [ ] `irisStyle` — стиль райдужної оболонки: `solid` (як зараз), `organic` (реалістичний із волокнами), `gemstone` (кристалічний блиск), `galaxy` (космічна текстура всередині)
- [ ] `eyelashStyle` — стиль вій: `natural`, `glamour` (густі та довгі), `minimal`, `none`
- [ ] `eyeHighlightStyle` — тип блікa в оці: `standard`, `double-spark` (два бліки), `star-glint`, `none`
- [ ] `heterochromia` toggle — різні кольори лівого й правого ока (`eyeColorLeft` / `eyeColorRight`)

### C2. Рот і зуби

- [ ] `toothStyle` — `normal`, `fangs` (вже є), `gap-tooth` (щербинка), `braces` (брекети), `sharp-teeth` (гострі зуби як у акули)
- [ ] `mouthShape` — форма рота в спокої: `default`, `small`, `wide`, `pouty` (пухлі губи), `thin`
- [ ] `tongueColor` — кастомний колір язика (для фентезі-персонажів)

### C3. Деталі обличчя

- [ ] `freckles` toggle + `frecklesDensity` + `frecklesColor` — веснянки
- [ ] `faceScar` — шрам на обличчі: `none`, `cheek-slash`, `eye-scar`, `cross-forehead`
- [ ] `beautyMark` — мушка на обличчі: `none`, `left-cheek`, `right-cheek`, `under-eye`, `chin`
- [ ] `facePaint` — бойовий / фестивальний розпис: `none`, `tribal`, `cat-whiskers`, `butterfly`, `under-eye-stripe`

### C4. Вуха розширення

- [ ] `earDecoration` — `none`, `piercing`, `cuff`, `feather` — декор вушка для elf/pointy/normal
- [ ] Покращені elf/pointy вуха з рухом при нахилі голови (ref-mutation)

## Фаза D — Тіло та пропорції

Мета: розширити контроль над тілом аватара за межі голови та плечей.

### D1. Розширені пропорції

- [ ] `eyeSize` (0.8 – 1.3) — масштаб очей
- [ ] `eyeSpacing` (0.8 – 1.2) — відстань між очима
- [ ] `noseSize` (0.7 – 1.3) — розмір / промінентність носа
- [ ] `mouthSize` (0.7 – 1.3) — масштаб рота
- [ ] `chinLength` (0.8 – 1.2) — довжина підборіддя (додатково до `faceShape`)

### D2. Деталі тіла

- [ ] `skinTexture` — `smooth` (default), `battle-scars`, `tattoo-tribal`, `scales` (для фентезі-драконів)
- [ ] Руки / кисті (хоча б верхня частина) для костюмів із відкритими плечима
- [ ] `bodyType` — вплив на ширину торсу та силует: `slim`, `default`, `athletic`, `petite`

## Фаза E — Глибина виразності

Мета: більше інструментів для live-виразності під час стріму.

### E1. Нові емоції та мікро-вирази

- [ ] `smirk` — хитра напівпосмішка (асиметричний рот + піднята одна брова)
- [ ] `pout` — надуті щоки (SVG-деформація обличчя + збільшені щоки)
- [ ] `wink` — підморгування (одне око закрите, інше відкрите з бліком)
- [ ] `bored` — нудьга (важкі повіки, відвернений погляд, позіхання)
- [ ] `determined` — рішучість (стиснуті зуби, звужені очі, вогонь у погляді)

### E2. Реактивні візуальні ефекти

- [ ] Animated particle system — конфігуровані частки навколо аватара (зірки, серця, вогонь, сніжинки, сакура) прив'язані до емоцій або ручного тригеру
- [ ] Aura / glow outline — сяючий контур навколо аватара (кольоровий, пульсуючий)
- [ ] Background reactions — фонові ефекти, прив'язані до емоцій (екран трясеться при `angry`, дощ при `cry`, зоряне небо при `starry`)

### E3. Позування

- [ ] `headTilt` presets — збережені нахили голови (кокетливий, задумливий, зухвалий)
- [ ] Gesture hotkeys — швидкі жести: помахати, показати знак миру ✌️, відправити повітряний поцілунок

## Підсумок

Поточний аватар уже має сильну базу з **10+10 зачісок**, **14 костюмів**, **10 аксесуарів**, **7 зіниць**, **5 форм обличчя**, **5 форм очей**, **3 арт-стилів** та **16 емоцій**. Цей роадмеп додає:

- **~20 нових візуальних елементів** (зачіски, костюми, аксесуари, зіниці)
- **Поглиблену кольорову систему** (мульти-тон волосся, губи, патерни одягу, матеріали аксесуарів)
- **Деталізацію обличчя** (вії, гетерохромія, веснянки, шрами, розпис, іриси)
- **Анатомічне розширення** (пропорції очей/рота/носа, body types)
- **Live-виразність** (5 нових емоцій, частки, аура, жести)
- **Зручності UI** (thumbnails, randomize, undo/redo, ШІ-палітри)
- **4 нових showcase-пресети**
