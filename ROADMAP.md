## Definition of Done для нової властивості аватара

Щоб роадмапа більше не розходилась із кодом, кожен новий конфіг-параметр вважається
зробленим лише коли оновлені **всі** шари:

`types.ts` (union/поле) → рендер у `components/avatar/` → контрол у `components/sidebar/` →
`sanitizeConfig.ts` (whitelist/clamp + unit-тест) → ШІ-схема у `server.ts` →
i18n `en.ts` + `uk.ts` → за потреби — Telegram-стікери та export.
